# WanderLust – Travel Accommodation Platform

WanderLust is an Airbnb-inspired full-stack web application that allows users to explore, create, and manage property listings and share reviews.

## Live Demo
https://wunderlust-project.onrender.com

## Topics Covered
- Node.js and Express.js
- MongoDB and Mongoose
- EJS Templating
- RESTful APIs and CRUD Operations
- Authentication and Authorization using Passport.js
- Session Management and Middleware
- Image Uploads using Cloudinary
- Bootstrap
- Git and GitHub
- Deployment using Render

## Features
- User Signup and Login
- Create, Edit, and Delete Listings
- Upload Property Images
- Add and Manage Reviews
- Authentication and Authorization

## Installation
1. Clone the repository.
2. Run `npm install`.
3. Configure the required environment variables.
4. Run `node app.js`.
